# CHISEFRK API

Personal API and utility collection.

## Base URL

https://chisefrk.github.io/chisefrk-api/

## Current endpoints

### API Info

GET `/api/info.json`

### Quotes

GET `/api/quote/all.json`

Contains the CHISEFRK quote dataset.

## Architecture

This project is intentionally static and hosted with GitHub Pages.

No external backend is required for the static datasets.
